# Agrinho-2026
Projeto Agrinho 2026
Agro forte, futuro sustentável: equilíbrio entre produção e meio ambiente”. 

Link do Site: https://luizaruiz-sys.github.io/Agrinho-2026/

Tema: Produzir hoje, preservar para amanhã. 

Objetivo:
Apresentar a importância da agricultura sustentável, destacando como a produção de alimentos pode ocorrer de forma responsável, com o uso de tecnologias e práticas que preservam o meio ambiente, garantindo qualidade de vida para as atuais e futuras gerações.
